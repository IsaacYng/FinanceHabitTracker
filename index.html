Firebase Setup - 1 Choti Matra:
1. Firebase Console > Authentication > Email/Password ON, Google ON, Anonymous ON
2. Realtime Database > Rules > Tala ko rules Publish:
{
  "rules": {
    ".read": true,
    ".write": true
  }
}
Firestore hoina! Realtime Database ho. Firestore ma yo rules halda error aauchha.
