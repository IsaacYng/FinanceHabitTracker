Firebase Setup (1 choti):
1. Realtime Database ON — Auth chahindaina (Single User Mode)
2. Realtime Database > Rules > Publish (Single User — users / main matra):
{
  "rules": {
    "users": {
      "$uid": {
        ".read": "auth != null && auth.uid == $uid",
        ".write": "auth != null && auth.uid == $uid"
      }
    }
  }
}
Audit Note: Public rules (read/write true) le aru le pani data padhna sakchhan. Mathi ko auth-based rules use garnus. Firestore hoina! Realtime Database ho. Data: users / UID / transactions, bank_accounts, udharo, budgets, habit_checks, mero_users
